## Description

ActionbarPlus-Masque adds optional [Masque](https://www.curseforge.com/wow/addons/masque) support to [ActionbarPlus](https://www.curseforge.com/wow/addons/actionbarplus)'s action bar buttons, letting you apply any installed Masque skin to your ActionbarPlus bars for a consistent look across your UI.

### Requirements

- [ActionbarPlus](https://www.curseforge.com/wow/addons/actionbarplus)
- [Masque](https://www.curseforge.com/wow/addons/masque)

### Examples Skins/Themes

- Cirque
- Caith
- Serenity

Installing this addon will automatically install both dependencies if you don't already have them.

Once installed, your ActionbarPlus buttons automatically join the "ActionbarPlus" skin group in Masque's options panel — no extra setup required. Choose a skin, adjust backdrop/shadow/gloss/pulse options, and it applies directly to your bars.

### Masque Settings Shortcut

Right-click an ActionbarPlus bar and choose **Masque Settings** to open Masque's options directly to the ActionbarPlus skin group.
